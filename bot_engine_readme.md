# FootballPoints House Bot Engine

Shared bot controller for:
- Whot
- Dice
- Snooker

Rules:
- Start stake: N1000
- After loss: N2000
- After second loss: N3000
- After third consecutive loss: pause bot
- Any win resets stake to N1000

The bot is an opponent and availability system. Game engines remain responsible for legal gameplay and fair random events.
